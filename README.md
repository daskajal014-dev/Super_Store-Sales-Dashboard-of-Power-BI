# Power BI Sales Dashboard

## Project Overview

This project is an interactive Power BI dashboard created to analyze sales data and generate meaningful business insights.

## Tools Used

* Microsoft Power BI
* Power Query
* DAX
* Excel

## Key Features

* Interactive dashboard
* KPI cards
* Sales performance analysis
* Product and brand analysis
* City-wise sales analysis
* Monthly sales trends
* Interactive filters and slicers

## Learning

Through this project, I learned how to clean and transform data using Power Query, create data models and relationships, use DAX for calculations, and build interactive dashboards to present business insights.

## Objective

The objective of this project is to analyze sales performance and present key insights through an easy-to-understand interactive dashboard.
